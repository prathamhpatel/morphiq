# Morphiq

## Typeface

The site is set in **Author** by Satya Rajpurohit (Indian Type Foundry), from
[Fontshare](https://fontshare.com/fonts/author) — free for personal and
commercial use. The files live in `public/fonts/`; see the README there.

Without them the site falls back to Product Sans / Inter / system sans and
still builds and runs.
